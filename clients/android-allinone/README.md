# NimbusSeat All-in-One Android APK

Один APK, который содержит **всё**: лаунчер NimbusSeat (поиск хоста в LAN,
6-часовой таймер, старт сессии) **плюс встроенный open-source Moonlight**
([moonlight-android](https://github.com/moonlight-stream/moonlight-android),
GPL-3.0). Ничего не нужно скачивать из Play Market.

## Как собирается

GitHub Actions (workflow `Android All-in-One APK`):
1. клонирует moonlight-android v12.1 с сабмодулями (стриминговое ядро C);
2. накладывает наш код из `overlay/` (лаунчер + discovery + REST-клиент);
3. `patch_moonlight.py` меняет applicationId на `app.nimbusseat.client`
   (по просьбе автора Moonlight не выпускать чужие сборки под `com.limelight`),
   метку приложения на NimbusSeat и делает наш экран стартовым;
4. собирает `assembleNonRootRelease` и подписывает **release-ключом**
   (keystore хранится в GitHub Secrets).

## Облачный экран: любая цель

Экран «Облако» не зашит на один репозиторий. В ⚙ задаются `repo`, `token`,
`workflow`, ветка и файл сессии, и `inputs` запуска в JSON — то есть один APK
может подключаться и к NimbusSeat-Runner, и к хабу `zen-panel`, и к форку.
Два пресета (NimbusSeat / zen-panel хаб) переключают цель одним тапом.
Понимаются оба формата сессии; адрес берётся из
`mobile` → `url` → `novncUrl` → `novnc` → `web` → `desktop` → `hubUrl`.

Подключение — **стрим всегда во весь экран**. `🖥 Полный экран` открывает сессию
развёрнутой (панель спрятана), `📱 Панель управления` показывает панель лёгким
полупрозрачным листом поверх экрана, `↗ Ссылка в браузере` отдаёт адрес системе.
Никакой прозрачной «кнопки развернуть» поверх потока нет: такая ловушка касаний
делает рабочий стол полностью неактивным, а тап по нему должен идти самому
столу. Долгий тап тоже отдан столу (WebView не перехватывает его под выделение
текста), а «Назад» показывает/прячет панель.

Экран показывается, как только в сессии есть адрес, — даже если `state` не
записан; пустой токен больше не мешает читать публичные репозитории (заголовок
`Authorization` не шлётся, если токена нет).

### zen-panel: хаб, а не голый VNC

У zen-panel две цели. Голый VNC (`live/session-vnc.json`, `vnc.html`) открыт без
пароля, но **не несёт звука** и даёт стандартное noVNC-управление. Хаб
(`live/session-hub-linux.json`, поле `mobile` = `/m`) отдаёт экран плюс
**OPus-звук** (мост `/ws/audio` через PulseAudio), виртуальную мышь с колесом,
zoom «заполнить/1:1», клавиатуру и полный экран с поворотом — поэтому пресет
«zen-panel хаб» ведёт именно туда.

Хаб закрыт гейтом: без `?zt=<токен>` он отвечает **401** на каждую страницу и
на звуковой сокет. Поэтому в цели есть поле **«Гейт хаба ?zt=»**: оно же
передаётся джобе как input `token` (гейт работает, только если хаб запущен с
ним), и добавляется к адресу как `?zt=`. Оставьте поле пустым — хаб поднимется
 без гейта, и `/m` откроется и без `?zt=`.

Голый `vnc.html` от noVNC дополняется `?autoconnect=1&resize=scale` — иначе видна
тёмная табличка «Connect» и рабочий стол 1:1 (на телефоне выглядит как чёрный
экран).
