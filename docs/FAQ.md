# FAQ

**Мешает ли гостевая сессия хозяину ПК?**
Нет. ASTER V7 изолирует места: у гостя свой рабочий стол (виртуальный монитор
Duo), своё аудиоустройство и только инжектируемый ввод Moonlight. Хозяин видит
свой экран, слышит свой звук, его клавиатура и мышь не «дёргаются».

**Почему Duo, а не обычный Sunshine/Apollo?**
Duo — форк Apollo с поддержкой нескольких одновременных сессий и виртуальных
дисплеев, что и нужно для независимого второго места.

**Можно ли играть из интернета?**
Намеренно нет: firewall-правила и проверка подсети в API пропускают только LAN.
Не пробрасывайте порты и не включайте UPnP для портов стрима.

**Что происходит через 6 часов?**
Предупреждения за 30/10/5 минут, минута на сохранение, затем стрим обрывается
и хост уходит на 15-минутный перерыв. Всё настраивается в `config.json`.

**Сколько клиентов одновременно?**
Один гость за раз — это менеджер сессий одного «второго места». Хозяин на
Месте 1 не считается.

**Легально ли это?**
Duo/Apollo/Sunshine и Moonlight — open source (GPL). ASTER V7 — платный,
нужна лицензия IBIK на 2 места. Игры и их EULA — ваша ответственность.
